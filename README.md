# Мастерская оживления идей — мини‑сайт (горизонтальная карта)

## Что это
Одностраничный сайт‑«карта»: путь от **искры идеи** до **живой игры**, как алгоритм + настольная бродилка.
Сверху переключаются режимы («линзы»):

- **для участников** — про самореализацию и игру
- **для родителей** — про пользу и навыки
- **для вдохновения** — референсы и примеры
- **для начала** — вопросы и подсказки по запуску этапа

У каждого шага вокруг «летают» полупрозрачные слова, которые меняются при переключении линзы.

---

## Структура
- `index.html` — разметка
- `style.css` — общий стиль
- `mobile.css` — адаптив
- `content.js` — весь контент шагов, слова, списки, связи (редактируйте тут)
- `script.js` — логика (рендер карты, переключение линз, панель справа)
- `media/` — иконки, doodle‑svg, (и ваш шрифт)

## Как запустить локально
### Вариант 1 (самый простой)
Откройте `index.html` в браузере.

### Вариант 2 (если браузер ругается на загрузку файлов)
Поднимите локальный сервер (например, VS Code Live Server).

## Как залить на GitHub Pages
1. Создайте репозиторий и закиньте сюда файлы.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Сайт станет доступен по ссылке Pages.

## Как менять/добавлять шаги
Откройте `content.js`.

### Добавить шаг
Добавьте объект в `nodes`:
- `id` (уникальный)
- `title`, `subtitle`
- `x`, `y` (позиция на карте)
- `words` (плавающие слова по линзам)
- `lensText` (абзац справа)
- `list` (пункты справа)

### Соединить шаги
В `edges` добавьте:
```js
["fromId","toId"]
```
