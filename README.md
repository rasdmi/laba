# Фабрика детских идей — лендинг (Tilda-like)

## Как редактировать максимально удобно
- Все тексты и ссылки лежат в одном файле: **content.js**
- Вёрстка — блоками (как в Тильде): `index.html`
- Стили: `style.css` + адаптив: `mobile.css`

## Что нужно поменять сразу
В `content.js` замени:
- `portfolioHref: "https://example.com"` на ссылку на твой сайт.

## Запуск
Открой `index.html` или через VS Code Live Server.
